# Midori High — redesign visuel

Ce paquet modernise l'interface tout en conservant les fichiers applicatifs existants. Le logo fourni par l'utilisatrice est stocké dans `midori-high-logo.jpg` et référencé par la page de connexion et la barre latérale.

## Installation GitHub Pages
1. Téléchargez puis décompressez le ZIP.
2. Ouvrez le dossier `midori-high-main` dans l'archive.
3. Téléversez/remplacez les fichiers et dossiers qu'il contient à la racine du dépôt GitHub (pas le dossier parent `midori-high-main` lui-même si votre dépôt publie déjà ses fichiers à la racine).
4. Gardez `config.js` du projet existant si vous avez déjà configuré la nouvelle URL et la clé Supabase.
5. Après le commit, attendez GitHub Pages puis faites Ctrl+F5.

Note : il s'agit d'une refonte visuelle. Elle ne garantit pas à elle seule la compatibilité de chaque module avec les tables du nouveau schéma Supabase.
